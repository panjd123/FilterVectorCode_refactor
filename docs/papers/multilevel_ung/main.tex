\title{\system: Prefix-Frontier Entries and Predicate-Safe Block Navigation for Filtered Vector Search}

\begin{document}
\begin{abstract}
Label-filtered approximate nearest-neighbor search must connect eligible
vectors without letting metadata processing dominate search. In a
containment-based index, replacing dense group relations by a prefix tree
changes which entry groups are required; retaining the original entries can
leave eligible branches unreachable. We present \system, which couples a
terminal-prefix forest with a bitmap-backed covering frontier, and introduces
independently constructed blocks for coarser predicate-safe navigation.
A block is authorized when its root prefix contains the query labels. Search
states carry a physical level and expand only that level's edges. We prove
label-plane coverage and conditional predicate safety, while treating
finite-budget ANN Recall as an experimental property. A structural rule
instantiates overlay count and thresholds without query-performance
calibration, and batched GPU tasks accelerate construction. On Amazon,
matched 0L Trie/entry search is 2.77--18.43$\times$ faster than the optimized
LNG system at three measured selectivities below 6\%, but is slower or lacks
a Recall crossing on broader workloads. The automatic LNG-base plan,
\texttt{2L[L|LT]}/DRH-v1, achieves 14.40--26.70$\times$ over optimized
\texttt{0L[L]} at 60--99\% selectivity. These are screening
results at measured Recall@10 crossings; held-out regressions remain.
The fastest composed GPU-assisted build takes 141.27 seconds versus
190.38 seconds for the original CPU base, with query-quality equivalence
across construction backends still to be established.
\end{abstract}
